# Stage Themes V5

Current website character-strip assets for the seven Lab-in-the-Loop stages.

- `01-measure-agatha-three-poses.webp`: Agatha Christie detective theme, preserved from the accepted Measure set.
- `02-model-three-poses.webp`: Zhuge Liang-inspired strategist theme, unified purple palette, no `7` clothing.
- `03-design-golf-three-poses.webp`: golf experiment-design theme, enlarged to match the Measure scale.
- `04-coordinate-football-three-poses.webp`: football coordination theme with Green `#046A38`, Red `#DA291C`, football shoes, and a clearer 4-2-3-1 formation board.
- `05-monitor-formula-three-poses.webp`: Formula racing monitor theme with red racing suit, cap/helmet, telemetry, sensors, and number `7` branding.
- `06-readout-tennis-three-poses.webp`: tennis readout theme for perturbation/drug-response feedback.
- `07-update-training-three-poses.webp`: K-pop training-system update theme for feedback, refinement, and iteration.

The active website uses WebP. Original transparent PNGs and green-screen sources were archived under `_archive/2026-07-24-unused-assets/optimized-png-sources/`.
