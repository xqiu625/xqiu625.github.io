01
Loop stage one · Agatha Christie casework

Measure.

Handle biological data like an Agatha Christie case file: every sample, outlier, and batch effect may be a real clue or a red herring, and nothing is concluded before the evidence holds up.

🔍 Case file · clues, red herrings & witnesses
01
🔍
Agatha Christie lens · Trustworthy observation

Separate clues from red herrings.

This is the Measure stage of the lab loop: archive the clues, identify reliable witnesses, remove dramatic but misleading red herrings, and admit only a trustworthy chain of evidence into the model.

CluesReal biological signals that need to be preserved, labeled, and traced.
WitnessesCell types, sample origins, and experimental conditions define the evidence context.
Red herringsNoise, batch effects, contamination, and outliers should not mislead the model.
01.1Quality Control & PreprocessingClean the case file first: remove low-quality samples, doublets, contamination, and batch artifacts before they enter the reasoning chain.→ 01.2Cell Annotation & Type IdentificationIdentify each witness: cell type determines what the evidence means and how the model should interpret the signal.→
Trustworthy observation enters the model
02
Loop stage two · LEGO

Model.

Like a LEGO build, modeling starts with the parts list before snapping anything: which pieces exist, in what order, and what each connection will hold.

🧱 LEGO plan · sort before snapping
02
🧱
LEGO plan · Representation

Sort the bricks before the build.

This is the Model stage of the lab loop: understand the structure, variables, and causal constraints of the biological system before the next experiment. From tokens to attention, from trajectories to causal inference, each method assembles the parts list before the next brick.

02.1Tokenization StrategiesBreak DNA, RNA, or protein sequences into basic units a model can learn.→ 02.2Attention MechanismsDecide which signals matter most in a complex context.→ 02.3Trajectory InferenceInfer possible state-change paths from static snapshots of cells.→ 02.4Optimal Transport & WassersteinUse mathematics to compare and align different cell populations.→ 02.5Contrastive LearningLearn embeddings by pulling similar samples together and pushing different ones apart.→ 02.6Pretraining ObjectivesMasked, causal, and denoising objectives that teach models from unlabeled data.→
The model chooses the next experiment

Loop stage five · Formula 1

Monitor.

Track the run in real time.

Loop stage six · Tennis

Readout.

Tennis maps to experimental readout: the serve is only the beginning — the point is decided by how you read the return.

🎾 Tennis · read the experimental return

🎾
Experimental return · Biological response

Read the return.

This is the Readout stage of the lab loop: the model proposes an intervention and the experiment responds. The key is not simply that an experiment was run, but that the gap between prediction and response becomes readable.

06.1Perturbation ModelingPredict and explain cellular responses after genetic or chemical intervention.→ 06.2Drug Response PredictionCompare predictions with experimental readouts and learn from the mismatch.→
